# CalorieTracker

A mobile-friendly app that uses **Deep Learning** (EfficientNet) to identify food from images and estimate calories.

## Features

- Food recognition using a trained deep learning model.
- Calorie estimation with portion adjustment.
- Optional Flask backend for meal logging.
- Mobile frontend built with React Native (Expo).

## Model

- Trained on **Food-101** dataset using TensorFlow.
- Converted to **TFLite** for mobile inference.

## Run Locally

### Backend

```bash
cd backend
pip install -r requirements.txt
python app.py
```
